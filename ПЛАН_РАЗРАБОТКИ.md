# План разработки проекта "SimpleBank - Многооконный интерфейс"

## 📋 Обзор проекта
Разработка многооконного WPF приложения для банковской системы с разделением функционала по ролям пользователей.

---

## 🎯 Этап 1: Подготовка структуры проекта

### 1.1 Создание папки View
- **Задача**: Создать папку `View` в проекте для размещения дополнительных окон
- **Действия**:
  - Создать папку `View` в корне проекта
  - Убедиться, что `MainWindow` остается в корне проекта

### 1.2 Подготовка ресурсов
- **Задача**: Добавить графические ресурсы для единого стиля
- **Действия**:
  - Создать папку `Resources` или `Images` в проекте
  - Добавить файлы:
    - `logo.png` - логотип банка (для заставки и окон)
    - `icon.ico` - иконка приложения
  - Настроить `BuildAction` для изображений:
    - Логотип для Splash Screen: `BuildAction = SplashScreen`
    - Остальные изображения: `BuildAction = Resource`

## 🏠 Этап 3: Реализация главного окна (MainWindow)

### 3.1 Дизайн главного окна
- **Задача**: Создать интерфейс главного меню приложения
- **Элементы интерфейса**:
  - **Заголовок окна**: "Главное меню приложения" / "SimpleBank"
  - **Логотип**: Отображение логотипа банка
  - **Три основные кнопки меню**:
    1. "Клиент банка" (Bank Client)
    2. "Сотрудник банка" (Bank Employee)
    3. "Системный администратор" (System Administrator)
  - **Кнопка "Выход"** (Exit) - в правом верхнем углу или внизу
  - **Подвал**: Текст "Банковское приложение SimpleBank"

### 3.2 Программная логика MainWindow
- **Обработчики событий**:
  ```csharp
  - btnClient_Click()      → Открыть UserInformationWindow
  - btnEmployee_Click()    → Открыть AuthorizationWindow (режим сотрудника)
  - btnAdministrator_Click() → Открыть AuthorizationWindow (режим администратора)
  - btnExit_Click()        → App.Current.Shutdown()
  - Window_Closing()       → Подтверждение закрытия
  ```

### 3.3 Навигация из MainWindow
- При выборе "Клиент банка":
  - Создать `UserInformationWindow`
  - Скрыть главное окно (`this.Hide()`)
  - Показать окно клиента (`ShowDialog()`)
  - После закрытия показать главное окно (`this.Show()`)

- При выборе "Сотрудник банка" или "Администратор":
  - Создать `AuthorizationWindow` с передачей роли
  - Скрыть главное окно
  - Показать окно авторизации модально
  - После закрытия показать главное окно

## 🔐 Этап 4: Окно авторизации (AuthorizationWindow)

### 4.1 Создание окна
- **Расположение**: `View/AuthorizationWindow.xaml` и `View/AuthorizationWindow.xaml.cs`
- **Наследование**: `Window` из `System.Windows`

### 4.2 Элементы интерфейса
- **Заголовок**: "Авторизация пользователя"
- **Логотип**: Отображение логотипа банка
- **Поля ввода**:
  - Текстовое поле "Введите логин" (TextBox)
  - Поле пароля "Введите пароль" (PasswordBox)
- **Кнопки**:
  - "Войти" (Login) - основная кнопка
  - "Назад" (Back) - возврат в главное меню

### 4.3 Программная логика
- **Конструктор**: 
  - Принимает параметр `userRole` (Employee/Administrator)
  - Сохраняет роль для дальнейшего использования
- **Обработчики событий**:
  ```csharp
  - btnLogin_Click()     → Проверка логина/пароля → Открытие соответствующего окна
  - btnBack_Click()      → this.Close()
  - Window_Closing()     → Подтверждение закрытия
  ```
- **Логика авторизации**:
  - Простая проверка (можно использовать статические данные)
  - После успешной авторизации:
    - Если роль = Employee → открыть `BankEmployeeWindow`
    - Если роль = Administrator → открыть `SystemAdministratorWindow`
  - Закрыть окно авторизации
  - Показать окно функционала

## ⚠️ Этап 9: Подтверждение закрытия окон

### 9.1 Реализация события Closing
- **Задача**: Добавить подтверждение закрытия для всех окон
- **Реализация**:
  ```csharp
  private void Window_Closing(object sender, CancelEventArgs e)
  {
      MessageBoxResult result = MessageBox.Show(
          "Вы уверены, что хотите закрыть окно?",
          "Подтверждение",
          MessageBoxButton.YesNo,
          MessageBoxImage.Question);
      
      if (result == MessageBoxResult.No)
      {
          e.Cancel = true; // Отменить закрытие
      }
  }
  ```

### 9.2 Применение ко всем окнам
- Добавить обработчик `Window_Closing` в каждое окно:
  - MainWindow
  - AuthorizationWindow
  - BankEmployeeWindow
  - SystemAdministratorWindow
  - UserInformationWindow

## 🔄 Этап 10: Навигация между окнами

### 10.1 Схема навигации
```
MainWindow
    ├──→ UserInformationWindow (при выборе "Клиент банка")
    │       └──→ [Назад] → MainWindow
    │
    ├──→ AuthorizationWindow (при выборе "Сотрудник банка")
    │       ├──→ [Войти] → BankEmployeeWindow
    │       │               └──→ [Назад] → MainWindow
    │       └──→ [Назад] → MainWindow
    │
    └──→ AuthorizationWindow (при выборе "Администратор")
            ├──→ [Войти] → SystemAdministratorWindow
            │               └──→ [Назад] → MainWindow
            └──→ [Назад] → MainWindow
```

### 10.2 Паттерны навигации
- **Модальные окна**: Использовать `ShowDialog()` для окон авторизации
- **Скрытие главного окна**: `this.Hide()` перед показом дополнительного окна
- **Возврат**: `this.Show()` после закрытия дополнительного окна
- **Закрытие**: `this.Close()` для дополнительных окон
