# Структура проекта SimpleBank

## ✅ Созданная структура

```
SimpleBank/
├── App.xaml                    # Точка входа приложения
├── App.xaml.cs                 # Код приложения
├── MainWindow.xaml             # Главное окно (в корне проекта)
├── MainWindow.xaml.cs          # Код главного окна
├── View/                       # ✨ НОВАЯ ПАПКА - для дополнительных окон
│   └── .gitkeep                # Маркер папки
├── Resources/                  # ✨ НОВАЯ ПАПКА - для графических ресурсов
│   ├── README.txt              # Инструкция по ресурсам
│   └── ИНСТРУКЦИЯ_ПО_РЕСУРСАМ.md  # Подробная инструкция
├── Properties/                 # Свойства проекта
├── bin/                        # Скомпилированные файлы
├── obj/                        # Временные файлы компиляции
└── SimpleBank.csproj           # Файл проекта
```

## 📋 Что было сделано

### ✅ Этап 1.1: Создание папки View
- Создана папка `View/` для размещения дополнительных окон
- Папка готова для добавления окон:
  - `AuthorizationWindow`
  - `BankEmployeeWindow`
  - `SystemAdministratorWindow`
  - `UserInformationWindow`

### ✅ Этап 1.2: Создание папки Resources
- Создана папка `Resources/` для графических ресурсов
- Добавлены инструкции по использованию ресурсов
- Готова для добавления файлов:
  - `logo.png` - логотип банка
  - `icon.ico` - иконка приложения

## 📝 Следующие шаги

1. **Добавить ресурсы** (вручную в Visual Studio):
   - Добавить `logo.png` в папку `Resources`
   - Добавить `icon.ico` в папку `Resources`
   - Настроить Build Action для файлов

2. **Настроить Splash Screen** (следующий этап):
   - Установить Build Action для `logo.png` как `SplashScreen`

3. **Создать окна** в папке `View`:
   - AuthorizationWindow
   - BankEmployeeWindow
   - SystemAdministratorWindow
   - UserInformationWindow

## 🔍 Проверка структуры

Папки созданы и готовы к использованию. При добавлении файлов в Visual Studio они автоматически появятся в Solution Explorer.
