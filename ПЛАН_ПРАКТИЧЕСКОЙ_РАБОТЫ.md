## Этап 3: Реализация класса BankAccount (Банковский счет)

### 3.1. Создание файла класса
- Создать файл `BankAccount.cs` в папке `Models/`
- Определить namespace: `SimpleBank.Models`

### 3.2. Перечисление для статуса счета
- Создать enum `AccountStatus`:
  - `Open` (открыт)
  - `Closed` (закрыт)
  - `Bankrupt` (банкрот)

### 3.3. Поля класса
- `AccountNumber` (string) - номер счета
- `OpeningDate` (DateTime) - дата открытия счета
- `Owner` (Client) - данные владельца (объект класса Client)
- `Balance` (decimal) - сумма на счету
- `DepositTermDays` (int) - срок вклада (дни)
- `Status` (AccountStatus) - статус счета

### 3.4. Приватные (private) расчетные методы
- `CalculateDepositEndDate()` (DateTime) - определение даты окончания вклада
  - Возвращает `OpeningDate + DepositTermDays`
- `UpdateStatusByBalance()` (void) - изменение статуса вклада в зависимости от суммы
  - Логика: если баланс < 0 → статус "банкрот", если баланс = 0 и счет закрыт → "закрыт", иначе "открыт"

### 3.5. Публичные (public) методы
- `Deposit(decimal amount)` (bool) - пополнение счета
  - Проверка: amount > 0
  - Увеличивает баланс на amount
  - Вызывает `UpdateStatusByBalance()`
  - Возвращает true при успехе, false при ошибке
  
- `Withdraw(decimal amount)` (bool) - снятие со счета
  - Проверка возможности снятия:
    - amount > 0
    - Balance >= amount
    - Status == Open
  - Уменьшает баланс на amount
  - Вызывает `UpdateStatusByBalance()`
  - Возвращает true при успехе, false при ошибке
  
- `Transfer(BankAccount targetAccount, decimal amount)` (bool) - перевод средств на другой счет
  - Проверка:
    - amount > 0
    - targetAccount != null
    - targetAccount != this (нельзя переводить на тот же счет)
    - Balance >= amount
    - Status == Open
    - targetAccount.Status == Open
  - Выполняет снятие с текущего счета и пополнение целевого счета
  - Возвращает true при успехе, false при ошибке

### 3.6. Конструкторы
- **Конструктор по умолчанию**: инициализирует все поля значениями по умолчанию
- **Конструктор с параметрами**: принимает все необходимые параметры для инициализации счета

### 3.7. Метод вывода информации (опционально)
- `DisplayInfo()` (void) - вывод полной информации о счете, включая данные владельца

## Технические детали

### Типы данных
- `string` - для текстовых полей (ФИО, паспорт, номер счета)
- `DateTime` - для дат (рождение, открытие счета, окончание вклада)
- `decimal` - для денежных сумм (баланс)
- `int` - для срока вклада в днях
- `enum` - для статуса счета

### Логика проверок
- Все методы с операциями должны проверять валидность входных данных
- Методы возвращают `bool` для индикации успеха/неудачи
- При необходимости можно использовать исключения (`ArgumentException`, `InvalidOperationException`)

### Связь классов
- `BankAccount` содержит объект типа `Client` в поле `Owner`
- Это демонстрирует композицию (has-a relationship)
