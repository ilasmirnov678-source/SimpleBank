# Инструкция по добавлению ресурсов в проект SimpleBank

## 📁 Необходимые файлы

### 1. Логотип банка (`logo.png` или `logo.jpg`)
- **Назначение**: Отображение логотипа в окнах приложения и на заставке
- **Рекомендуемые размеры**: 
  - Для заставки: 400x200 пикселей или больше
  - Для окон: 200x100 пикселей
- **Формат**: PNG (с прозрачностью) предпочтительнее, или JPG
- **Где использовать**: 
  - Splash Screen (заставка при запуске)
  - Верхняя часть всех окон приложения

### 2. Иконка приложения (`icon.ico`)
- **Назначение**: Иконка для всех окон приложения и ярлыка
- **Размеры**: Multi-icon файл с размерами:
  - 16x16 пикселей
  - 32x32 пикселей
  - 48x48 пикселей
  - 256x256 пикселей
- **Формат**: ICO
- **Где использовать**: Иконка в заголовке всех окон

---

## 🔧 Как добавить ресурсы в Visual Studio

### Шаг 1: Добавление файлов
1. Скопируйте файлы `logo.png` и `icon.ico` в папку `Resources`
2. В Visual Studio: Правой кнопкой на папке `Resources` → `Add` → `Existing Item...`
3. Выберите файлы `logo.png` и `icon.ico`
4. Нажмите `Add`

### Шаг 2: Настройка Build Action

#### Для логотипа (заставка):
1. Выберите файл `logo.png` в Solution Explorer
2. В окне Properties установите:
   - **Build Action**: `SplashScreen`
   - Это позволит использовать изображение как заставку при запуске

#### Для логотипа (в окнах):
Если нужен тот же файл и для окон:
- Создайте копию `logo.png` с именем `logo_window.png`
- Установите **Build Action**: `Resource`

Или используйте один файл с **Build Action**: `Resource` и настройте заставку отдельно.

#### Для иконки:
1. Выберите файл `icon.ico` в Solution Explorer
2. В окне Properties установите:
   - **Build Action**: `Resource`

### Шаг 3: Проверка
После добавления файлов они должны появиться в Solution Explorer в папке `Resources`.

## 💻 Использование в коде

### Логотип в XAML:
```xml
<Image Source="pack://application:,,,/Resources/logo.png" 
       Width="200" Height="100" />
```

### Иконка окна:
```xml
<Window Icon="pack://application:,,,/Resources/icon.ico"
        ...>
```

### Через ресурсы приложения (в App.xaml):
```xml
<Application.Resources>
    <BitmapImage x:Key="LogoImage" 
                 UriSource="pack://application:,,,/Resources/logo.png" />
</Application.Resources>
```

Затем в окнах:
```xml
<Image Source="{StaticResource LogoImage}" />
```

## 📝 Примечания

- Если у вас нет готовых файлов логотипа и иконки, можно использовать временные изображения для разработки
- Для создания иконки из изображения можно использовать онлайн-конвертеры (например, convertio.co, ico-convert.com)
- Рекомендуется использовать PNG для логотипа из-за поддержки прозрачности
- Иконка должна быть в формате ICO для корректного отображения в Windows
